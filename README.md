# Parbe 

**Parbe** is a full‑stack **MERN + AI** learning accelerator application designed to help users learn faster and smarter using AI.  
It provides an intelligent learning experience by combining modern web technologies with AI‑driven features.

-  Built with **MongoDB, Express.js, React, Node.js (MERN stack)**

-  Intelligent recommendations and progress tracking

##  Getting Started

### Prerequisites

Make sure you have installed:

- Node.js (v14+ recommended)
- npm or yarn
- MongoDB instance (Atlas or local)

### Setup

1. **Clone the repository**
    ```bash
    git clone https://github.com/Parisa-Reza/parbe.git
    cd parbe
    ```

2. **Install dependencies (backend)**
    ```bash
    cd server
    npm install
    ```

3. **Install dependencies (frontend)**
    ```bash
    cd ../client
    npm install
    ```

4. **Environment Variables**

    Create a `.env` file in both `server` and `client` folders (copy from `.env.example`):

    ```bash
    cp .env.example .env
    ```

    Add your own credentials (MongoDB, API keys etc.).
